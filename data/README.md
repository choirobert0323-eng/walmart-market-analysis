# External input files

The historical notebook expects `dowandjones.csv`, `nasdaq.csv`, `walmart.csv` and `sandp500.csv` relative to the notebook working directory. These files are not bundled. The current release does not establish their original providers, date ranges or redistribution terms.

`Walmart_Sales.csv` found elsewhere locally is not assumed to be the stock-price input; sales and stock-market datasets are different sources.

See the report link in the root README for original presentation material. Keep raw inputs local and obtain permission from each source before redistribution.
